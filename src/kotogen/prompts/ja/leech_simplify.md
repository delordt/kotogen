日本語で日本語を学ぶ学習者が何度もまちがえる語彙カード（リーチ）を作り直す。語も、その中心の意味も**変えずに**、次はもっと**覚えやすく**なるように書き直す。カードの文はすべて日本語で書く。

## フィールド（キー "fields"）
- `Expression`：ふりがな `漢字[かな]` の形の語。変えない（ふりがながまちがっているときだけ直す）。
- `Translation`：意味を、その語よりやさしい日本語で短く。いちばんふつうの意味を**一つ**だけ残し、ほかの意味はけずる。まちがいの原因は、たいていそこにある。
- `Context`：同じ意味のほかの語とまぎれているなら書く。リーチの正体は、たいていそれ。下の決まりを見ること。
- `Notes`：役に立つなら、**短い**覚えるヒントを足す（はっきりしたニュアンス、よくあるわな）。リーチなら、それは Note を書く理由になる。そうでなければ空。
  漢字の助けはここに入れない（それは "kanji_help" に入る）。
- `Example` と `ExampleTranslation`：その語をしっかり結びつける、**とても**短くて具体的な、ふだんの文。長すぎたり、わかりにくかったりする例文はかえる。`ExampleTranslation` は、例文を、その語を使わずにやさしい言葉で言いかえた文。両方書くか、両方空にする。

## 漢字の助け（キー "kanji_help"）：漢字の**意味**だけ
`Expression` が**いくつかの**漢字で書かれているなら、語の順に、それぞれの意味を書く。文にせず、お話も作らず、短い言葉で：`学 まなぶ + 生 いきる`。
- 漢字を部品や部首に分けない。漢字の形は漢字デッキのカードの仕事で、語のカードの仕事ではない。
- 語全体の意味ではなく、**漢字の**意味を一語で：`生 いきる` で、「学生」ではない。
- 漢字が**一つだけ**のとき（`橋`、`食[た]べる`）：`kanji_help` = ""。その意味は Translation で、もうカードにある。
- 音で選ばれた漢字（当て字：`寿司`、`珈琲`）：`kanji_help` = ""。その意味は学習者をまよわせる。
- 頭に語そのものをくり返さない（もう `Expression` にある）。「漢字 = 」のような前置きなしに、すぐ最初の漢字から始める。
- 語の意味をくり返さない（もうカードにある）。「→ …」のようなまとめも書かない。
- まぎらわしさの行も「≠ …」も書かない。漢字の意味だけ。
**短い一行**（50字くらい）。それ以外は `kanji_help` = ""。

## ふりがなの決まり
`漢字[かな]` で、漢字のまとまりの前には半角スペースを一つ（`今日[きょう]は 暑[あつ]い`）。この形で書くのは `Expression` と `Example`。`Translation`、`ExampleTranslation`、`Notes` には読みを付けなくてよい。カードに出すとき、プログラムが付ける。`kanji_help` は書いたまま入る（読みは付かない）。

## 種類のちがうカード（キー "category"、なくてもよい）
このデッキにあるのは**語彙**だけで、語彙でないカードは、何度もまちがえる理由になりやすい。`Expression` が語彙でないなら、`category` キーを足す：

- `grammar`：規則、助詞だけのもの（は、が、を…）、接尾辞、文法の言い方（〜ている、〜たら、〜ながら）。
- `sentence`：語のはずのところにある、文まるごとや節。
- `fragment`：それだけでは決して使わないかけら（複合語の一部、はなれた送りがな）。

三つの値はプロトコルなので、書いてあるとおりのまま、英語で書く。となりの `reason` は日本語で、とても短く書く。

**迷ったら、キーを書かない**：決まった言い方、複合語、オノマトペ、助数詞、よく使う固有名詞は語彙。むずかしいだけの語は、種類がちがうわけではない。このキーは作り直しのかわりにはならない：ふつうの答えも書く。

## 答え
前後に何も書かず、JSON だけを返す。"fields" には、**本当に**変えたフィールドだけを入れる：
```json
{"reason": "カードを何がやさしくするか", "fields": {"Translation": "…"}, "kanji_help": "...",
 "category": {"type": "grammar", "reason": "動詞の接尾辞で、語ではない"}}
```
