日本語で日本語を学ぶ学習者のために、Anki の日本語の文法カードの中で、対象のカードと**重なる**もの、またはまぎれるものはどれかを見つける。

どのカードも、日本語の文の中の**一つ**の空欄 `{{c1::…}}` で、**一つ**の文法の規則（`Rule`）を練習する。表には、空欄のある文とヒントが出る：`Translation`（空欄の文法を使わない言いかえ）、`Target`（空欄の意味を表す言いかえの部分）、`Hint`（活用させる語）、`Nuance`。学習者は、かくれた形を答える。

候補（`index` で示す）のそれぞれに、判定を**一つ**する。三つの判定はプロトコルなので、書いてあるとおりに書く：

- `duplicate`：二枚が**同じ**問題を聞いている。同じ文で同じ規則か、とても近い文で、一枚がわかればもう一枚も答えられる。一枚あれば足りる。
- `confusable`：表で見分けのつかない別の二枚。一枚のヒントで、もう一枚の答えにも同じように行ける（同じ言いかえ、規則ととなりの規則：ながら／つつ、ために／ように）。学習者は、どちらの形が聞かれているのかわからない。
- `different`：それぞれ自分の問題を持つ二枚。

同じ規則を二つのちがう文で練習する二枚は `different`：規則はいくつかの文で覚えるもので、カードのシリーズはそのためにある。

`confusable` の候補には、ヒントで二枚をどう見分けるかを、`card`（対象のカード）と `other`（候補）に書く。フィールドは `Nuance` と `Hint` だけで、変える必要があるものだけ。`Nuance` は意味の短いヒントで、日本語で書き、規則の名前も形も決して言わない。読みは付けない。フィールド名はノートタイプのスキーマなので、書いてあるとおりに使い、名前を変えたり訳したりしない。

JSON だけで答え、`reason` は日本語で書く：

```json
{
  "verdicts": [
    {"index": 0, "verdict": "duplicate", "reason": "同じ文で、同じ空欄"},
    {"index": 1, "verdict": "confusable", "reason": "どちらも「〜と同時に」と言いかえられる",
     "card": {"Nuance": "二つのことを同時に"}, "other": {"Nuance": "〜のに、かたい言い方"}}
  ]
}
```

キーはプロトコルなので、書いてあるとおりに使い、名前を変えたり訳したりしない。判定のない候補は `different` として読む。
