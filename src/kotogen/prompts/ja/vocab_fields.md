**Context：同じ意味（Translation）をもつ語を見分けるもの。** 一つの意味を、いくつかの語が分け合うことがある。着る、かぶる、はくは、どれも「身につける」と言える。`意味 → 語` のカードには「身につける」しか出ないので、正しい答えが三つあることになる。Context は、答えを一つにするためのもの。問題といっしょに、意味の下に出る。語を思い出す手がかりにはなるが、答えを言ってはいけない。

- 「**どれ？**」に答えるもので、「どういう意味？」には答えない。1〜4語の名詞句にし、活用した動詞も文も使わない。○「身につける」＋ *上半身に*（着る）／ *頭に*（かぶる）。× *服を体の上のほうに着ること*：説明が答えを言ってしまう。
- 同じ意味のライバルがあるときだけ書き、ないときは `""`。ライバルの中で、いちばん基本の語のカードには Context を付けない。ほかのカードの Context がそれを指してくれる（「血」：血は何も付けず、血液は *医学の言葉*）。一つの束の中に、見分けのつかない二枚を残さない。同じ Context を二つ作らない。
- **Translation の中に、かっこで補足を書かない**（「流れる（液体が）」）。それは Context なのに、Context だと言っていないだけ。ライバルがあれば Context に書き、なければどこにも書かない。
- よく見分けられるもの：分野（*医学の言葉*）、使い方の決まり（*生き物について*）、自動詞と他動詞、外来語と和語（*外来語*）、たとえとしての使い方。どのカードにも当てはまる言葉（*ふつうの言葉*、*一般的*、*中立的*）は使わない。何も教えないから。
- **レジスターだけを書かない**（*かたい*、*くだけた*、*書き言葉*）。何とくらべてなのかがわからない。ライバルと見分けるのがレジスターなら、相手を名前で言う：航空機 *飛行機よりかたい*。書き方が同じ二枚なら、相手を読みで言う：*しおからいよりくだけた*。
  × *かたい言葉*、*くだけた言葉*、*文語*、*丁寧な形*：食物 → *食べ物よりかたい*、風呂屋 → *銭湯よりくだけた*。使い方が限られるレジスターはタグにもなり（下を見ること）、そのバッジは裏で答えといっしょに出る。問題からは見えないので、それしか見分けるものがない語には、やはり Context がいる。
  召し上がる「食べる」に `Register::敬語::尊敬語` → *食べるの尊敬語*。
- 意味がちがう二つの語は、レジスターでくらべない：文章はまとまった文で、文は一つの文。ちがいは意味にあり、それは Translation が言っている。
- Context には読みが付かない。その語のレベルで読める漢字だけを使い、むずかしい言葉はひらがなで書く。

**Notes：ふつうは空。** たいていのカードは空にする。答えのあと、復習のたびに読まれるものだから。Translation、Context、バッジが言わないことを教えるときだけ、次のどれかの理由で書く：
- Translation だけではわからないこと：浴衣 → *夏に着る、木綿の着物*；
- Translation が見せていない二つ目の意味：下ろす「下のほうへ動かす」→ *お金を引き出すという意味もある*；
- 使い方のわな：全然「少しも〜ない」→ *くだけた話し言葉では、よい意味を強めることもある*；語を名前で言うくらべ：*≠ 赤ちゃん*。

してはいけないこと：Translation を言い直すだけの説明（「引き止める」→ *人が帰らないようにする*）、Context やバッジがもう言っていること（バッジ「口」と *くだけた*）、Translation に入っていること（「少しも〜ない」→ *否定といっしょに使う*）、Tags が持っている文法の名前。Notes が名前を出す語（*≠ 行く*、*どちらの*）はそのまま残す。どの語とくらべるのかを言っているから。一行、50字くらいまで。Notes の漢字に読みを付ける必要はない。カードに出すとき、プログラムが付ける。

**レジスター、話し手、方言：タグ**。その語の使い方がそれに限られるときだけ付ける。どのレジスターでも、だれでも、どこでも使える語には付けない。たいていの語には付かない：
- `Register::敬語::尊敬語` 尊敬語（いらっしゃる）｜`Register::敬語::謙譲語` 謙譲語（参る、拝見）｜`Register::丁寧語` もともと丁寧な語（ございます）
- `Register::改まった語` 改まった語で、ふつうの会話ではかたい（友人、本日）｜
  `Register::文章語` 書き言葉、文語（即ち）｜`Register::口語` くだけた話し言葉（やっぱ）｜
  `Register::俗語` 俗語｜`Register::蔑称` 人を見下す言葉｜`Register::古語` 古くなった言葉（便所）
- `Speaker::男性語`（俺、僕）｜`Speaker::女性語`（あたし）
- `Dialect::関西弁`（ほんまに）

レジスターのタグは、それだけで一つのタグになる。ほかのタグとはスペースで分け、つなげない：`Verb::五段動詞 Register::敬語::尊敬語` で、`Verb::五段動詞::Register::敬語::尊敬語` ではない。二つ付く語もある：俺には `Register::口語` と `Speaker::男性語`。まちがって付けやすいタグなので、付ける前に三つ確かめる：
- `Register::改まった語` と `Register::文章語`：日本人が友だちに言って、かたく聞こえたり、書き言葉に聞こえたりするか。しないなら付けない。危険、準備、女性、機会、行う、朝食はふつうの漢語で、レジスターではない。
- `Register::口語`：手紙の中や目上の人の前で、場ちがいに聞こえるか。聞こえないなら付けない。みんな、さっき、つもり、久しぶりには付けない。くだけた使い方が一つだけある語にも付けない：全然は否定といっしょならどこでも言い、肯定のくだけた使い方は Note に書く。
- `Register::蔑称` は人をばかにしたり、見下したりする言葉（貧乏人）で、悪い意味をもつ語（くだらない、理屈）ではない。
