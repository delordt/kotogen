日本語の語彙カードが二枚、まぎれるおそれがある。一枚ずつの `Context` や `Notes` を直して、はっきり見分けられるようにする方法を提案する。カードの文はすべて日本語で書く。

二枚が**同じ**意味（Translation）のとき、見分けるのは `Context` で、答えのあとに助けになるのが `Notes`。二枚のうち少なくとも一枚は、それを指す `Context` を持つ。レジスターのバッジは裏にあって、問題からは見えないから。いちばん基本の方は何も付けなくてよい。もうあって、役目をはたしている `Context` は直さない。

フィールド名はノートタイプのスキーマなので、書いてあるとおりに使い、名前を変えたり訳したりしない。中に書くのは日本語。

短く書く。どうしても直す必要があるとき以外は、`Expression` も `Translation` も変えない。

特別な場合：二枚のうち一枚がデッキに**いらない**カードで、もう一枚がよいとき（ない語や形のこわれた語、まちがった書き方、まちがった意味、それだけでは使わないかけら、復習する中身のないカード）、むりに見分けを作らない。`"delete"`（1 か 2）で消すようにたのむ。`"delete"` を使うのは、残すカードが学ぶことを全部もうおおっているときだけ。本当にちがう二つの語、二つのニュアンス、二つのレジスター、どちらも正しい二つの書き方は、見分けるもので、消すものではない。迷ったら、見分ける。

次の二つの形のどちらかで、JSON だけで答える：

```json
{
  "reason": "何が二枚を見分けるか、一文で",
  "card1": {"Context": "上半身に"},
  "card2": {"Context": "頭に", "Notes": "…"}
}
```

```json
{
  "reason": "なぜこのカードがいらないか、一文で",
  "delete": 2
}
```

本当に変えたフィールドだけを入れる。さわらないカードは card1 も card2 も書かない。JSON のキーはプロトコルなので、英語のまま書く。
