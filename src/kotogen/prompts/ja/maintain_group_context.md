日本語の語彙カードが何枚か、**同じ**意味（Translation）を分け合っている。`意味 → 語` の表で、学習者に見えるのはその意味と `Context` フィールドだけ。それが見分けないかぎり、問題には正しい答えがいくつもあり、どれも見つけられない。それぞれのカードに、そのカードだけを指し、ほかのどのカードも指さない `Context` を付ける。カードの文はすべて日本語で書く。

束について決まっていること：

- **Context はいっしょに読む**：どの Context も、束の二枚を指せてはいけない。答える前に、たがいにくらべて読む。
- **レジスターのバッジは見分けない。** `Tags=` の付いたカードにはレジスター（`Register::改まった語`、`Speaker::男性語`…）があり、カードはそれを裏で答えといっしょに見せる。問題からは見えない。そのレジスターがカードを見分けるものなら、`Context` がもう一枚の名前を出してそれを言い（*友達よりかたい*）、もうそれを言っている `Context` は残す。
- もうあって役目をはたしている Context は直さず、もうあるくらべ（*今よりかたい*）もそのまま残す。束のほかのカードにも同じように当てはまる Context は直し、何も教えない Context は取り消す。
- **広すぎる意味は、見分けるのではなく、直す。** 意味が正しくないか短すぎるためだけに束に入っているカードには、正しい `Translation` を書く。やさしい日本語で短く、「；」も「／」もかっこも使わない：要点は「大事なこと」ではなく「話や文章の中心になること」。それでカードは束から出て、`Context` は空にする。本当に同じ意味の二つの語を見分けるために、意味を書き直さない。それは意味をそのままにして、`Context` をもらう。かっこの補足（「おば（よその人の）」）は意味ではない。問題の中に入れられた `Context` だ。
- **もうカードを見分けている `Notes`**（*生き物について*）は、かくれた `Context` を持っている：それを `Context` にし、`Notes` からその部分を取りのぞき、残りはそのままにする。`Context` が言うことは、言葉を変えて書いてあっても `Notes` から取りのぞく（`Context` *雨や雪の量*、`Notes` *雨について、雪について*）。あなたが返す `Notes` は、フィールド全体を入れかえる。

短く書く。`Expression` は決して変えず、`Translation` は上の理由のときだけ変える。

束の二枚が実は**同じ**語なら（同じ日本語の語が、二つの書き方か、二つのふりがなの切り方で書かれている）、二つの Context を作らない。`duplicates` で知らせる。一つの漢字の二つの読み（末[すえ]、末[まつ]）は二つの語。本当にちがう二つの語は見分けるもので、知らせるものではない。迷ったら、見分ける。

JSON だけで答える。キーはプロトコルなので、書いてあるとおりのまま：

```json
{
  "reason": "何が束を見分けるか、一文で",
  "cards": [
    {"n": 1, "Context": "お金をもらう仕事"},
    {"n": 2, "Context": "しなければならないこと", "Notes": "…"},
    {"n": 3, "Context": ""},
    {"n": 4, "Translation": "話や文章の中心になること", "Context": ""}
  ],
  "duplicates": [[5, 6]]
}
```

`n` はリストの中のカードの番号。`cards` には本当に変えたカードだけを入れ、重なりがなければ `duplicates` は書かない。
