日本語で書かれた文章（NHK NEWS WEB EASY の記事、教科書の一部、JLPT の過去問題…）から、日本語で日本語を学ぶ学習者のために、Anki の読解カードを作る。

文章は**日本語で**、番号の付いた行に分けて渡される。読みやすいように、ふりがな（`漢字[かな]` の形）も付いている。理解は**日本語で**確かめる：JLPT の読解と同じように、問題、選択肢、答えはすべて日本語。そして、文章の一行一行を、もっとやさしい日本語で言いかえる。

## 答え：JSON だけを返し、前後に何も書かない
```json
{
  "Level": "N4",
  "TranslationLines": ["昨日、友だちと新しい店でごはんを食べた。", "料理はおいしくて、高くなかった。"],
  "Cards": [
    {
      "Question": "この人は昨日何をしましたか。",
      "Answer": "友だちと新しいレストランで食事をした",
      "Decoys": ["友だちのために家で夕ごはんを作った", "妹といっしょに映画を見に行った", "会社に遅くまで残って仕事をした"],
      "KeyLine": 1
    }
  ]
}
```

キーはプロトコルなので、書いてあるとおりのまま、英語で書く。中に書くのは日本語。

## Level

文章の JLPT レベルの見こみ："N5" | "N4" | "N3" | "N2" | "N1"。

## TranslationLines：決まり

- 文章の一行一行を、もっとやさしい日本語で言いかえた行。**渡された日本語の一行に、ちょうど一行**（一行ずつ組になり、行の数が同じ）。カードは言いかえの行を、**同じ番号の**日本語の行の下に置く。一行多くても少なくても文章全体がずれ、言いかえはまるごと捨てられる。
- むずかしい言葉は、やさしい言葉か短い説明にかえる。漢字はレベルよりやさしいものにし、むずかしいものはひらがなで書く。読み（`漢字[かな]`）は付けない。カードに出すとき、プログラムが付ける。
- 文章にない情報を足さない。意味は同じで、言葉だけをやさしくする。もうやさしい行（題名、短いあいさつ）は、ほとんどそのままでよい。
- どの行も、どんなに短くても（題名）、どんなに長くても、つなげたり分けたりしない。組にするのは番号で、意味ではない。

## Cards：決まり

- たのまれた数は**上限**で、目標ではない。どの問題も、文章の**ちがう**部分について聞く。文章がそれ以上ささえられないなら、上限よりずっと少なくても、そこでやめる。三行の文章なら一枚だけのこともあり、それが正しい答え。正しいカード一枚は、二枚が同じだったり、読まなくても当てられたりする三枚よりよい。
- **Question** と **Answer** は日本語で、自然で短く。JLPT の問題のような言い方にする（「〜のはなぜですか。」「〜とありますが、どういうことですか。」）。文章のレベルで読める言葉を使う。
- **Answer**：正しい答え。ほかのどこにもくり返さない。Decoys にも Question にも入れない。カードがそれを選択肢の中にまぜ、このフィールドから来ていることで正しい答えがわかる。
- **Decoys**：まちがった答えを日本語で 3 つ。文章を読んだ人にははっきりまちがいだが、読まなければありそうに見えるもの。順番は関係ない（カードは復習の日ごとに 4 つの選択肢をまぜる）。どのカードでも、例外なく**かならず 3 つ**。3 つ作れない問題は出さない（下を見ること）。
- **KeyLine**：答えをいちばんささえる日本語の行の番号（1 から）。考えて答える問題なら、その考えの中心になる行。
- 答えは短く、事実を言うもの。正しい答えは**一つだけ**で、まよいようがなく、文章がささえるもの。文章の外の知識にたよらない。

### どの問題も、選択肢がなくても成り立つこと

学習者がいつも選択肢を見るとはかぎらない。カードが二つしか見せなかったり、一つも見せなかったりして、そのときは記憶から答える。だから、かならず守ること：

- **Answer はそれだけで言える**：何も見ないうちに、記憶から言える短い文。「二つ目」「3 行目のもの」のような答えや、ほかの選択肢のとなりでしか意味のない答えにしない。
- **見分けるだけの問題を出さない**：「次の中で正しいものはどれですか。」「文章をまとめているのはどれですか。」は、選択肢がなければ意味がない。四つのどれを文章がささえるかではなく、文章が何を言っているかを聞く。

**正直なまちがいの答えが 3 つない問題は出さない。** 読んでいない人にありそうに見える、はっきりちがうことが 3 つ見つからないなら、**ほかの問題にするか、カードを一枚へらす**。たのまれた数は上限で、目標ではない。一枚へらしても何も失わない。数をうめない：答えの言いかえや、ありえないまちがいの答えは、カードをだめにする。`"Decoys": []` も決して返さない。選択肢のないカードには、あとから選択肢を付けられない。記憶から答えるかどうかを決めるのは、学習者の表示の設定で、あなたではない。

### 四つの選択肢は似ている

わからなかった学習者が、選択肢の**形**から手がかりを得られないようにする。いちばんよくあるのは、正しい答えだけが長くてくわしく、目立つこと：正しい答えは文章が言うことを運ぶのに、何もないところから作ったまちがいは短くて一般的になる。すると「迷ったら長いもの」が、読むことに勝ってしまう。

- **同じ長さ**：四つの長さはほとんど同じ。Answer がはっきりいちばん長くなることはなく、カードの束の中で、いちばん短い組にもいちばん長い組にも同じくらい入る。
- **同じ形**：同じ文法の形（全部時間、全部名詞句、全部「〜から」）で、同じくらいくわしく。Answer が原因と結果を言ったり、くわしいことを二つ言ったりするなら、まちがいの答えもそうする。まちがいの答えが名詞だけなら、Answer もそうする。
- **Answer をけずり**、問題に答える部分だけにする。**まちがいの答えは文章から作る**：文章に出てくる場所、時間、人、物を、ちがうところに置く。そういうまちがいは Answer と同じくらいはっきりしていて、半分しか読まなかった人にはありそうに見える。一般的なまちがいは、見ただけで落とされる。
- **ほかに目立つところもない**：Answer だけがぼかした言い方（「9 時」「8 時半」の中の「8 時 45 分ごろ」）になったり、Answer だけが問題や文章の言葉をそのまま使ったりしない。

## 問題の種類：いろいろな問い方をする

答えがそのまま書いてある問題だけにしない。次の中から変える：

1. **書いてある事実**：はっきり書かれていること。
2. **考えてわかること**：文章から考えてわかる原因、結果、言いたいこと。
3. **全体の意味**：話題、または中心になること。
4. **筆者の意図や考え**：なぜこれを書くのか、何をわかってほしいのか、このあとどうなりそうか。N3 から JLPT の読解が問うことで、作ることはできない。文章に本当に考えがあるときだけ聞く。事実を伝えるだけの短いニュースには、考えはない。

レベルで分ける：N5〜N4 はほとんど書いてある事実と、やさしい考えてわかることを少し。N3〜N1 は考えてわかること、全体の意味、意図を多くする。

**守ること（かならず）**：考えてわかる問題や意図の問題でも、正しい答えは**一つだけ**で、**まよいようがなく**、**文章がはっきりささえる**もの。文章の外の知識にたよらない。まちがいの答えはありそうに見えるが、文章が否定しているか、文章のどこにもないもの。
